# B2B Lead Growth Engine – Talio | Blal Oussama

Site statique (une seule page HTML, 3 pages A4, schéma animé). Aucune dépendance, aucun build.

## Publier sur GitHub Pages
1. Créer un dépôt **public** sur GitHub (ex. `talio-lead-growth`).
2. Y déposer les fichiers de ce dossier (`index.html`, `.nojekyll`, `robots.txt`, `README.md`).
3. Settings > Pages > Source : *Deploy from a branch* > branche `main`, dossier `/ (root)` > Save.
4. Après environ une minute, le site est en ligne : `https://<pseudo>.github.io/<nom-du-depot>/`

## Notes
- Le site est public pour toute personne qui connaît l'adresse, mais il n'est pas indexé par les moteurs de recherche (`noindex`, `robots.txt`).
- Le bouton « Imprimer / PDF » produit les 3 pages A4 (version sans animation).
- Pour modifier un texte : éditer `index.html`, puis commit.
